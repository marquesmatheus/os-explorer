Clocks, GHz e Arquitetura de Processadores

O clock é o pulso cardíaco do processador. Cada ciclo, ele executa um conjunto de instruções. Quanto mais GHz, mais ciclos por segundo — mas não é tudo.

Como o Clock Funciona

Formato do Sinal de Clock

O sinal de clock é uma onda quadrada que alterna entre 0 e 1. A cada borda de subida (rising edge), o processador executa operações nos registradores.

Fórmula fundamental:

f = 1 / T

f = frequência (Hz) | T = período (segundos)
Exemplo: 1 GHz = 1.000.000.000 Hz → T = 1 ns por ciclo

Por que GHz Não é Tudo

Um processador de 3 GHz pode ser mais lento que um de 2.5 GHz. Por quê? IPC (Instructions Per Cycle).

Performance = IPC x Clock (GHz)

Um Ciclo do Processador

A cada ciclo de clock, a CPU passa por estas etapas (pipeline clássico de 5 estágios):

1. Fetch

Lê a instrução da memória (ou cache) usando o PC (Program Counter). Se o dado não está no cache, penalty de ~100 ciclos.

2. Decode

Decodifica a instrução em sinais de controle. LEA, ADD, MOV viram sinais para ALU, registradores e memória.

3. Execute

ALU processa: soma, multiplicação, comparação. Branches decidem se pula ou não (branch prediction ajuda).

4. Memory

Acessa dados da memória (LOAD/STORE). Cache L1: ~1 ciclo, L2: ~4, L3: ~12, RAM: ~100+ ciclos.

5. Write Back

Escreve o resultado de volta no registrador. Completou um ciclo inteiro de instrução.

Caches e Latência

O cache é como ter o ingrediente na bancada vs ir no depósito. Quanto mais longe, mais tempo perdido.

Nível Tamanho típico Latência (ciclos) Tempo real Comparação
L1 Cache 32-64 KB ~1 ciclo ~0.3 ns Acender uma fósforo
L2 Cache 256 KB - 1 MB ~4-10 ciclos ~1-3 ns Acender um fogareiro
L3 Cache 8-64 MB ~30-50 ciclos ~10-15 ns Andar até o depósito
RAM (DDR5) 16-128 GB ~100-200 ciclos ~30-60 ns Ir ao supermercado
NVMe SSD 500 GB - 4 TB ~10,000+ ciclos ~10,000 ns Ir ao depósito do centro

Verificar Seu Sistema

# Ver clock atual do processador (Linux)
cat /proc/cpuinfo | grep "cpu MHz"

# Ver frequência atual (macOS)
sysctl -a | grep hw.cpufrequency

# Ver todos os cores e suas frequências
lscpu | grep "CPU MHz"

# Monitorar em tempo real
watch -n 1 "cat /proc/cpuinfo | grep 'cpu MHz'"

# Windows
wmic cpu get CurrentClockSpeed,MaxClockSpeed,Name

# Ver cache do processador
lscpu | grep -i cache
