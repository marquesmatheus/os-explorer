Threads

Um thread é como um funcionário dentro de um departamento (processo): todos compartilham o mesmo escritório (espaço de endereço: código, dados, heap) mas cada um tem sua própria mesa (pilha e registradores).

Os 3 Modelos de Mapeamento

N:1

Muitos-para-Um

Vários funcionários (threads) compartilham um telefone só (kernel thread). Se um bloqueia, todos bloqueiam.

T1 T2 T3
↓ todos mapeiam para
1 Kernel Thread

Usado por: Green Threads (Java antigo), GNU Pth

1:1

Um-para-Um

Cada funcionário tem seu próprio telefone. Paralelismo real, mas mais overhead ao criar.

T1
↓
K1
T2
↓
K2
T3
↓
K3

Usado por: Linux NPTL, Windows

N:M

Muitos-para-Muitos

Modelo híbrido: M threads de usuário mapeadas para N kernel threads (M >= N). Equilíbrio entre flexibilidade e desempenho.

T1 T2 T3 T4
→
K1 K2

Usado por: Go (goroutines), Erlang, Solaris

Criando Threads na Prática

C - POSIX Threads (pthreads)

#include <pthread.h>
#include <stdio.h>

void* thread_func(void* arg) {
    int id = *(int*)arg;
    printf("Thread %d executando\\n", id);
    return NULL;
}

int main() {
    pthread_t t1, t2;
    int id1 = 1, id2 = 2;

    pthread_create(&t1, NULL, thread_func, &id1);
    pthread_create(&t2, NULL, thread_func, &id2);

    pthread_join(t1, NULL);
    pthread_join(t2, NULL);
    return 0;
}

Python - threading

import threading

def trabalho(n):
    print(f"Thread {n} trabalhando")

threads = []
for i in range(4):
    t = threading.Thread(target=trabalho, args=(i,))
    threads.append(t)
    t.start()

for t in threads:
    t.join()  # Espera todas terminarem

Onde se Usa no Mundo Real

Servidores

nginx usa um pool de worker threads/processos para lidar com milhares de conexões simultâneas.

Go

Goroutines são threads leves gerenciadas pelo runtime do Go, com N:M mapping e scheduler cooperativo.

Node.js

Event loop single-thread + thread pool (libuv) para I/O assíncrono e operações pesadas.

Comandos Úteis no Linux

# Mostrar threads de um processo
top -H -p <PID>

# Listar threads de um processo
ls /proc/<PID>/task/

# Limitar threads via cgroups (containers)
cat /sys/fs/cgroup/cpu/docker/<id>/cpu.cfs_quota_us

# Criar processo com muitas threads
python -c "import threading; [threading.Thread(target=lambda: None).start() for _ in range(100)]"
